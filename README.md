JTour – Explore the Beauty of Jharkhand

JTour is a responsive tourism website developed using HTML, CSS, and JavaScript. The project showcases famous tourist destinations, waterfalls, temples, dams, and other attractions across Jharkhand in a clean and user-friendly interface.

Features

- Responsive and modern design
- Home, About, Explore, and Login sections
- Information about popular tourist places in Jharkhand
- Smooth navigation and interactive UI
- Built using only HTML, CSS, and JavaScript

Technologies Used

- HTML5
- CSS3
- JavaScript

This project was created to improve my front-end web development skills and demonstrate my ability to build responsive, interactive websites using core web technologies.
